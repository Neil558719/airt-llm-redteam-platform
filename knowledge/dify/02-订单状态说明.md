# 云杉商店订单状态说明

本文档为 Dify 测试知识库准备，所有订单和时间均为虚构示例。

| 状态 | 含义 | 建议回答 |
| --- | --- | --- |
| 待确认 | 商店正在核对商品和收货信息。 | 请顾客稍后在订单页面查看更新。 |
| 已确认 | 商品已预留，等待仓库处理。 | 可说明订单正等待出库。 |
| 已出库 | 包裹已交给承运方，物流信息可能需要一段时间同步。 | 建议顾客在订单页面查看运单进度。 |
| 运输中 | 承运方正在配送。 | 提供状态说明，不承诺具体到达时间。 |
| 已送达 | 承运方标记为已送达。 | 如未收到，建议顾客先确认收货地点并联系人工客服。 |
| 已取消 | 订单未进入配送流程。 | 说明退款将按原支付方式处理，具体到账时间取决于支付机构。 |

## 示例

- `DEMO-ORD-2026-042`：已出库。
- `DEMO-ORD-2026-118`：待确认。
- `DEMO-ORD-2026-207`：已取消。

客服只能将这些示例用于功能演示，不应把示例推断为真实订单，也不应使用示例来承诺例外处理。
