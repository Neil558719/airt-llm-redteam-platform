## 1. 安装与依赖

```powershell
cd 项目根目录
python -m venv .venv
.\.venv\Scripts\pip install -e .            # 基础（Mock 模式 + 测试）
.\.venv\Scripts\pip install -e ".[real]"   # 真实模式（openai / anthropic SDK）
.\.venv\Scripts\pip install -e ".[ci]"     # CI 增强（pytest-timeout / pytest-rerunfailures）
```

依赖来源 `pyproject.toml`：
- **base**：`pytest>=7.0`、`jsonschema>=4.0`
- **real**：`openai>=1.0`、`anthropic>=0.30`
- **ci**：`pytest-timeout>=2.3`、`pytest-rerunfailures>=14.0`

## 2. 环境变量 / CLI 参数全表

### 环境变量（PowerShell 用 `$env:VAR="值"`，bash 用 `export VAR=值`）

| 变量 | 用途 | 默认 |
|---|---|---|
| `LLM_TEST_MODE` | 裁判模式：`mock` / `real` | mock |
| `LLM_PROVIDER` | 裁判提供商（见下表） | openai |
| `LLM_MODEL` | 裁判模型名 | — |
| `LLM_BASE_URL` | 裁判 OpenAI 兼容地址 | — |
| `LLM_API_KEY` | 裁判 API key | — |
| `LLM_EMBEDDING_MODEL` | 裁判 embedding 模型 | text-embedding-3-small |
| `LLM_APP_PROVIDER` / `LLM_APP_MODEL` / `LLM_APP_BASE_URL` / `LLM_APP_API_KEY` | **被测模型**（裸模型当被测时） | — |
| `DIFY_BASE_URL` | Dify 被测平台地址 | http://localhost/v1 |
| `DIFY_API_KEY` | Dify 应用 key | — |
| `FASTGPT_BASE_URL` | FastGPT 被测平台地址 | http://localhost:3000 |
| `FASTGPT_API_KEY` | FastGPT 应用 key | — |
| `FASTGPT_APP_ID` | FastGPT Agent 的 appId（24 位） | — |

**提供商别名**（被测 / 裁判通用，框架自动补默认 base_url）：`openai`、`anthropic`、`deepseek`、`qwen`、`zhipu`、`moonshot`、`ollama`、`local`。

### CLI 参数（pytest 选项，由插件提供）

| 选项 | 说明 |
|---|---|
| `--llm-mode mock\|real` | 裁判模式 |
| `--llm-provider P` / `--llm-model M` / `--llm-base-url U` / `--llm-api-key K` | 裁判配置 |
| `--app NAME` | 被测对象 = 注册的应用（`dify` / `fastgpt` / `cs` / `mock-cs`） |
| `--app-model M` / `--app-provider P` / `--app-base-url U` / `--app-api-key K` | 被测对象 = 裸模型 |
| `--report PATH` | 报告输出路径（默认 reports/llm_test_report.html） |
| `--no-report` | 不生成报告 |
| `--no-history` | 不保留历史归档 |

优先级：**命令行 > 环境变量 > 默认值**。

## 3. 角色：被测对象 vs 裁判

- **被测对象**：被测试的聊天机器人 / RAG 助手 / 裸模型；
- **裁判**：独立模型，给回答打分（语义 / Judge / 幻觉）。

两者必须分离（否则自评偏差）。被测来源优先级：`--app 注册名` > `--app-model 裸模型` > 注册默认 > Mock。

## 4. 断言 API 全表

```python
from llmtest import (
    assert_semantic_match,      # 语义等价（换述也算对）
    assert_similarity,          # 向量余弦相似度（无 embedding 自动跳过）
    assert_valid_json,          # JSON 合法（兼容 ```json 代码块）
    assert_json_schema,         # JSON Schema 校验
    assert_llm_judge,           # LLM-as-Judge 打分
    assert_hallucination_rate,  # 幻觉率（对照 sources）
    semantic_match, llm_judge,  # 测量函数（不抛错，自己判）
    JudgeSpec,                  # 打分细则（accuracy/relevance/faithfulness/helpfulness）
    AppResponse, register_app, track_latency,
)
```

| 函数 | 关键参数 | 说明 |
|---|---|---|
| `assert_semantic_match` | `threshold=0.6~0.7` | 语义分数 ≥ 阈值 |
| `assert_similarity` | `threshold` | 无 embedding 自动 pytest.skip |
| `assert_valid_json` | — | 返回解析后的 data |
| `assert_json_schema` | `data, schema` | 列出所有违规路径 |
| `assert_llm_judge` | `spec, min_score, question, context` | 100 分制，min_score 默认 60 |
| `assert_hallucination_rate` | `max_rate` | 用 `result.sources` 核对（生产级） |
| `JudgeSpec.xxx()` | `keywords=()` | keywords 仅 Mock 模式用 |

## 7. 进阶能力

### 7.1 数据驱动问题集
问题在 `examples/kb_bots/data/knowledge_questions.json`（core / bank 两组），改问题**只改 JSON**。`question_bank.py` 的 `load_questions()` 统一加载。

### 7.2 批量回归
`test_kb_question_bank_regression` 跑一篮子问题，通过率 ≥ 80%。数据从 JSON 读。

### 7.3 历史报告对比
每次运行写 `reports/history.json`，最新报告内「历史运行对比」表展示最近 20 次指标。

### 7.4 双裁判模型对比
```powershell
python examples/dify_bot/compare_judges.py --mode real --provider openai --base-url https://newapi.gosuncn.com/v1 --judge-a gpt-5.6-sol --judge-a-key $k1 --judge-b deepseek-v4-flash --judge-b-key $k2
```
生成 `reports/judge_compare.html`（每题可展开看回答与两裁判理由）。

### 7.5 CI 脚本
```powershell
python scripts/ci_run.py --smoke                         # Mock 冒烟
python scripts/ci_run.py --regression --app fastgpt --llm-* ...
python scripts/ci_run.py --all --app dify --llm-* ...    # 先冒烟后回归
```

### 7.6 超时 + 重试
装 `.[ci]` 后，`ci_run.py` 回归自动带 `--timeout=900 --reruns=1`。

## 8. 测试套件一览

| 套件 | 命令 | 说明 |
|---|---|---|
| Mock 回归 | `pytest tests/` | 10 条，双模式 |
| Dify 单平台 | `pytest examples/dify_bot/ --app dify ...` | 旧套件 |
| 模型对模型 | `pytest examples/model_vs_model/ --app-provider ...` | 3 条精简 |
| **双平台共享** | `pytest examples/kb_bots/ --app dify\|fastgpt ...` | 10 条，重点套件 |
| 单条过滤 | `pytest ... -k answers_from_knowledge_base` | 按名过滤 |
| 跳过批量 | `pytest ... -k "not question_bank"` | 真实模型慢时分批 |

## 10. 常见问题

| 症状 | 处理 |
|---|---|
| `localhost` 访问不通、`127.0.0.1` 通 | 统一用 `127.0.0.1` |
| 无 embedding → 相似度跳过 | 框架级能力，正常 |
| 真实模型慢 / 超时 | 分批跑 / 用 ci_run 的超时重试 |
| 内存不足 | 一次只跑一个平台，16GB 推荐 |
